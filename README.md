# Houston Maternal Health Resources

Map-centric dashboard of maternal health resources in Houston / Harris County, built for
[maternal-health-resources-hou.com](https://maternal-health-resources-hou.com/) (Kinder Institute for Urban Research, Rice University).

- [`dashboard/`](dashboard/) — React + MapLibre app (see its README to run, deploy to S3 and embed)
- [`LOCATION_REVIEW.md`](LOCATION_REVIEW.md) — addresses checked by hand and still awaiting researcher review
- `Community_Resource_Directory_September_Update.xlsx` — source directory the map data was converted from
